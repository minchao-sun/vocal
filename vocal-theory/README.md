## 阅读说明

- 文档按**理解的逻辑**排序，后面的篇章会用到前面的概念，建议按顺序阅读。
- 每篇的结构是：本篇要点、正文、小结、案例分析、参考资料。**案例分析**是对学习者本人情况的分析，和理论部分分开，跳过不影响理解正文。
- 文中的解剖图来自 Wikimedia Commons 上的公有领域或知识共享授权资源，来源列在每篇末尾。图片保存在 [`images`](images/) 目录。
- 第二、三、四篇含有音频，建议在[网站](https://minchao-sun.github.io/vocal/)上阅读，可以直接播放。音频分两类：
  - **真人录音**：来自公开授权的研究数据集，标签由原研究者指定。放进文档之前都经过测量，确认测量结果和文中的说法一致。
  - **合成音频**：用程序按源—滤波理论生成，物理过程完全受控，用来演示共鸣原理。声音比较机械，不代表真人音色。
- 音频保存在 [`audio`](audio/) 目录，生成和处理脚本在仓库的 [`scripts/vocal-theory`](../scripts/vocal-theory/) 目录。

## 约定

- **音高记法**：采用科学音高记法，钢琴正中间的 C（中央 C）记为 C4，它上方的 A 记为 A4（440 Hz）。每到一个 C，数字加一，例如 B3 的上方一个半音是 C4。
- **专业术语**：第一次出现时给出中文名称和必要的英文或意大利文原文，方便你和其他资料对照。
