# 音乐学习书架

这个仓库收录音乐相关的学习用书，每本书放在一个独立的子目录里。

## 书目

| 书 | 简介 | 状态 |
|---|---|---|
| [声乐理论](vocal-theory/README.md) | 以流行音乐和音乐剧演唱为背景，系统梳理声乐中容易混淆的概念：发声原理、声带与闭合、声区、共鸣、呼吸等 | 编写中（已完成 3 篇） |

## 目录约定

每本书的目录结构相同：

```text
<书名目录>/
    README.md        本书的目录和阅读说明
    01-xxx.md        正文各篇，按编号排序
    02-xxx.md
    images/          本书用到的图片
```
